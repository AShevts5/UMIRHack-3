# Своя модель распознавания `rus_umir` (15.10.2026)

С 15.10 сервис по умолчанию читает документы моделью `backend/models/rus_umir.traineddata`
(`UMIR_OCR_LANGS=rus_umir+eng`). Это `rus` из `tessdata_best` 4.1.0, дообученная на наших
снимках, и сжатая в целочисленный вид, поэтому скорость та же, что у прежней `tessdata_fast`.

Вернуть прежнюю модель: `UMIR_OCR_LANGS=rus+eng` в `.env` (или в `/opt/umir-online-dean.env` на сервере).
Если файла `rus_umir` нет, сервис сам берёт обычный `rus`.

## Как подключается

Tesseract берёт все модели из одной папки. `config.with_own_model` собирает папку
`<temp>/umir-tessdata` (или `UMIR_TESSDATA_DIR`): системные `rus`, `eng`, конфиги и `rus_umir` из репы,
и `ocr_environment` выставляет на неё `TESSDATA_PREFIX`. В Docker ничего дополнительно ставить не нужно.

Время открытого набора: 36–42 с у обеих.

Целые страницы снимков test (109 снимков): доля слов эталона, найденных в тексте, 83,3% → 85,1%
(фото 75,9% → 77,3%). Поля печатного датасета почти не меняются (0.210 → 0.213): там упор
в парсер, «настоящие» справки написаны сплошным текстом.

Заодно: код направления, где точку на мелком снимке прочли как пробел или запятую
(`38 03.01`), теперь приводится к `38.03.01` (`parse_fields._normalize_field`).
