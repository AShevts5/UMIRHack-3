# Демонстрационный сценарий (≤ 3 минуты)

Все шаги выполняются на одном ноутбуке без сети. Ниже указано, что именно
говорить и что должно быть видно на экране. Основное время — проверка документов
(обязательная часть кейса), последние 40 секунд — путеводитель по вузу сверх кейса
(`docs/guide_features.md`).

Черновик ролика, который браузер записывает сам по этому сценарию, — `scripts/record_demo.cjs`;
текст озвучки с таймкодами — `docs/demo_voiceover.md`.

## Подготовка (за 5 минут до защиты)

```bash
python -m backend.scripts.tasks api        # терминал 1 -> http://127.0.0.1:8000
cd frontend && npm run dev                 # терминал 2 -> http://127.0.0.1:5173
```

Открыть `http://127.0.0.1:5173`, на экране входа нажать «Продолжить без входа»
(или войти заранее созданным пользователем), из холла открыть «Обращение в
деканат». В шапке должен гореть зелёный индикатор
«OCR на этом компьютере · rus_umir, eng». Резерв: собранный
`frontend/dist` раздаётся самим FastAPI по `http://127.0.0.1:8000/`.

Если файлов открытого набора под рукой нет, документы шагов берутся кнопками
«Пример 1–4» на стартовом экране проверки: полная справка, заявление без подписи и
даты, справка о практике в PDF и «фото под углом» для бонуса «плохие снимки» (там же
переключатель «После выравнивания / Исходник»). Для жюри можно запустить сервис с
`UMIR_DEMO_ACCOUNT=1`: на экране входа появится кнопка демо-аккаунта. Бонус «новый тип
через конфиг» показывается так: перезапустить сервис с
`UMIR_DOCUMENT_TYPES=examples/new-document-type/document_types.yaml
UMIR_RULES=examples/new-document-type/rules.md` и загрузить
`examples/new-document-type/work-certificate.png`.

Заранее открыть в третьем окне файл `reports/open-set.json`. Для шага 6 заранее
разрешить браузеру микрофон и геолокацию (или пользоваться кнопкой «Старт рядом с
вузом»).

## Шаг 0 (0:00–0:10) — вход и холл

Действие: на экране входа (корпус РИНХ слева, окно входа справа) нажать «Войти» —
камера приближается к дверям, открывается холл. Сразу открыть «Обращение в деканат».

Фраза: «Проверка документов — один из разделов приложения-путеводителя по вузу».

## Шаг 1 (0:10–0:40) — справка об обучении, полный документ

Действие: перетащить `open-001.png`, тип «Справка об обучении», нажать
«Проверить документ».

Что показать:

* вкладка «Распознанный текст» — реальный вывод OCR, не заранее
  заготовленный;
* карточка: 8 текстовых полей и 2 отметки, у каждой — ключ, пункт Положения и
  уверенность;
* статус «Все обязательные сведения присутствуют», источники `rule:3.1`,
  `rule:3.2`, `rule:3.3`;
* нажать на поле «Дата выдачи» — на изображении подсветится найденная зона;
* нажать на отметку «Печать вуза» — подсветится круглый макет (метод `colour`).

Фраза: «Подпись и печать определены по графике, а не по надписям: разбор
пикселей, а не поиск слова "Подпись"».

## Шаг 2 (0:40–1:10) — пропуск обязательного элемента

Действие: загрузить `open-014.png`, тип «Заявление на академический отпуск»,
нажать «Проверить документ».

Что показать: статус «Не хватает обязательных элементов», отсутствует
`leave_reason`, источник `rule:4.1`, остальные поля заполнены.

Затем задать вопрос «Укажи значение поля «Причина отпуска».» → `answerable=false`,
`value=null`, `sources=[]`, текст «Поле … не найдено в документе».

Фраза: «Отсутствие одного поля не мешает прочитать остальные, и сервис не
придумывает значение».

## Шаг 3 (1:10–1:35) — справка о практике, графические отметки

Действие: загрузить `open-021.png`, тип «Справка о практике», нажать
«Проверить документ», затем показать `open-023.png` (подпись отсутствует, печать
есть) и `open-004.png` (подпись есть, печати нет).

Что показать: одинаковый макет отметок, но разные результаты — флаги берутся из
изображения, а не из текста документа.

## Шаг 4 (1:35–1:50) — честное отсутствие ответа

Действие: задать вопрос «Какова стоимость обучения за следующий семестр?»
(есть готовая кнопка-подсказка).

Что показать: `answerable=false`, `value=null`, `sources=[]`, текст «В документе
и в Положении нет сведений по теме "стоимость обучения"…».

Дополнительно (если остаётся время): «Кто принимает окончательное решение?» →
`сотрудник деканата`, `rule:1.3`.

## Шаг 5 (1:50–2:05) — метрики

Действие: показать `reports/open-set.json` и терминал с командой

```bash
python -m backend.scripts.tasks evaluate
```

Что показать: `format_valid: true`, `field_accuracy_macro: 1.0`,
`validation_exact_match: 1.0`, `question_exact_match: 1.0`,
`documents: 30`, `questions: 120`, `errors: []`.

Фраза: «Это открытый набор организатора. Значения получены этой командой;
на закрытом наборе они могут быть ниже — мы этого не скрываем».

## Шаг 6 (2:05–2:45) — путеводитель по вузу (сверх кейса)

Действие и что показать, по 5–10 секунд на пункт:

* холл → «Факультеты и корпуса»: поиск «юрид», карточка с кабинетом, часами и
  подписью «Источник: rsue.ru»; пустые поля честно помечены «нет на сайте»;
* «Показать на карте» → корпус на карте OpenStreetMap; «Старт рядом с вузом» →
  «Идти» — человечек бежит к корпусу, у дверей «Войти в холл»;
* в холле «Спросить на посту охраны» → помощник здоровается «Приветствую Повелителя
  своего! Чем могу быть полезен?»; нажать микрофон и спросить голосом «Где деканат
  юридического факультета?» — ответ со ссылкой на источник и озвучкой;
* профиль → «Включить 2FA» → QR-код для Яндекс Ключа (секунду, без сканирования);
* (если есть время) телефон: та же страница, установленная как приложение (PWA).

Фраза: «Помощник не обращается к внешним нейросетям: он ищет ответ в справке, данных
вуза и Положении, а если не нашёл — так и говорит».

## Шаг 7 (2:45–3:00) — границы и развитие

Что сказать:

* сервис не сообщает «документ принят»: окончательное решение принимает
  сотрудник деканата (пункт 1.3 Положения);
* Положение «Меридиана» — единственная база правил этого кейса; правила реального
  вуза можно подключить только после официальной загрузки и согласования, без
  подмены документа. Поэтому и у РГЭУ, и у ЮФУ проверка документов идёт по
  Положению кейса;
* бонусы кейса, которые действительно работают: автоопределение типа (30/30),
  подсветка найденных зон, новый тип документа через `document_types.yaml`;
* сверх кейса: вход с 2FA и JWT, вход через Яндекс ID (нужны ключи приложения),
  справка по факультетам с официальных сайтов, карта вузов, AI- и голосовой
  помощник без внешних LLM, PWA и Android-проект на Capacitor.

## Резервные варианты

| Сбой | Что делать |
|---|---|
| OCR не установлен на машине жюри | Показать заранее записанный прогон (≤ 3 минуты) и `results.json` из репозитория |
| Не открывается Vite-порт | Открыть собранный UI на `http://127.0.0.1:8000/` |
| Зависла обработка | `open-0xx.png` обрабатывается ~3–4 с; при сбое перезапустить `python -m backend.scripts.tasks api` |
| Вопрос вне сценария | Задать произвольный вопрос: неизвестный запрос даёт честный отказ, а не выдумку |
| Браузер не дал микрофон или геолокацию | Спросить помощника текстом; на карте нажать «Старт рядом с вузом» |
| Нет интернета для тайлов карты | Карта без подложки, но метки и список корпусов работают; проверка документов от сети не зависит |
