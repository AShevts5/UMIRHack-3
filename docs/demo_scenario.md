# Демонстрационный сценарий (≤ 3 минуты)

Все шаги выполняются на одном ноутбуке без сети. Ниже указано, что именно
говорить и что должно быть видно на экране.

## Подготовка (за 5 минут до защиты)

```bash
python -m backend.scripts.tasks api        # терминал 1 -> http://127.0.0.1:8000
cd frontend && npm run dev                 # терминал 2 -> http://127.0.0.1:5173
```

Открыть `http://127.0.0.1:5173`. В шапке должен гореть зелёный индикатор
«Локальный OCR готов · tesseract 5.5.3 · rus, eng». Резерв: собранный
`frontend/dist` раздаётся самим FastAPI по `http://127.0.0.1:8000/`.

Заранее открыть в третьем окне файл `reports/open-set.json`.

## Шаг 1 (0:00–0:35) — справка об обучении, полный документ

Действие: перетащить `open-001.png`, тип «Справка об обучении», нажать
«Проверить документ».

Что показать:

* вкладка «Распознанный текст» — реальный вывод Tesseract, не заранее
  заготовленный;
* карточка: 8 текстовых полей и 2 отметки, у каждой — ключ, пункт Положения и
  уверенность;
* статус «Все обязательные сведения присутствуют», источники `rule:3.1`,
  `rule:3.2`, `rule:3.3`;
* нажать на поле «Дата выдачи» — на изображении подсветится найденная зона;
* нажать на отметку «Печать вуза» — подсветится круглый макет (метод `colour`).

Фраза: «Подпись и печать определены по графике, а не по надписям: разбор
пикселей, а не поиск слова "Подпись"».

## Шаг 2 (0:35–1:10) — пропуск обязательного элемента

Действие: загрузить `open-014.png`, тип «Заявление на академический отпуск»,
нажать «Проверить документ».

Что показать: статус «Не хватает обязательных элементов», отсутствует
`leave_reason`, источник `rule:4.1`, остальные поля заполнены.

Затем задать вопрос «Укажи значение поля «Причина отпуска».» → `answerable=false`,
`value=null`, `sources=[]`, текст «Поле … не найдено в документе».

Фраза: «Отсутствие одного поля не мешает прочитать остальные, и сервис не
придумывает значение».

## Шаг 3 (1:10–1:45) — справка о практике, графические отметки

Действие: загрузить `open-021.png`, тип «Справка о практике», нажать
«Проверить документ», затем показать `open-023.png` (подпись отсутствует, печать
есть) и `open-004.png` (подпись есть, печати нет).

Что показать: одинаковый макет отметок, но разные результаты — флаги берутся из
изображения, а не из текста документа.

## Шаг 4 (1:45–2:15) — честное отсутствие ответа

Действие: задать вопрос «Какова стоимость обучения за следующий семестр?»
(есть готовая кнопка-подсказка).

Что показать: `answerable=false`, `value=null`, `sources=[]`, текст «В документе
и в Положении нет сведений по теме "стоимость обучения"…».

Дополнительно (если остаётся время): «Кто принимает окончательное решение?» →
`сотрудник деканата`, `rule:1.3`.

## Шаг 5 (2:15–2:40) — метрики

Действие: показать `reports/open-set.json` и терминал с командой

```bash
python -m backend.scripts.tasks evaluate
```

Что показать: `format_valid: true`, `field_accuracy_macro: 1.0`,
`validation_exact_match: 1.0`, `question_exact_match: 1.0`,
`documents: 30`, `questions: 120`, `errors: []`.

Фраза: «Это открытый набор организатора. Значения получены этой командой;
на закрытом наборе они могут быть ниже — мы этого не скрываем».

## Шаг 6 (2:40–3:00) — границы и развитие

Что сказать:

* сервис не сообщает «документ принят»: окончательное решение принимает
  сотрудник деканата (пункт 1.3 Положения);
* Положение «Меридиана» — единственная база правил этого кейса; правила реального
  вуза можно подключить только после официальной загрузки и согласования, без
  подмены вымышленного документа;
* бонусы, которые действительно работают: автоопределение типа (30/30),
  подсветка найденных зон, новый тип документа через `document_types.yaml`;
* не реализованы и не заявляются: 2FA/JWT, OAuth, Capacitor, голосовой помощник,
  карта вузов, кабинет деканата.

## Резервные варианты

| Сбой | Что делать |
|---|---|
| OCR не установлен на машине жюри | Показать заранее записанный прогон (≤ 3 минуты) и `results.json` из репозитория |
| Не открывается Vite-порт | Открыть собранный UI на `http://127.0.0.1:8000/` |
| Зависла обработка | `open-0xx.png` обрабатывается ~3–4 с; при сбое перезапустить `python -m backend.scripts.tasks api` |
| Вопрос вне сценария | Задать произвольный вопрос: неизвестный запрос даёт честный отказ, а не выдумку |
